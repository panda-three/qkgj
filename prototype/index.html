轻客管家 · 页面原型

面向互联网教育机构的智能 CRM。以「线索 → 商机 → 客户」为主线， 覆盖公海池、部门权限体系与课程资源管理，用漏斗数据驱动转化决策。
本原型基于《功能需求文档 V1.0》构建，用于验证页面布局与交互流程。

11个页面
3类角色视角
40条业务规则映射
P0核心转化闭环
从登录页开始体验 → 直接进入数据看板

01 · 登录与首页

02 · 线索与公海（核心转化入口）

03 · 商机与客户（成交闭环）

04 · 资源与系统管理

原型说明

已实现的交互
  • · 侧边导航 + 面包屑 + 全局搜索的框架式布局
  • · 右上角角色切换：超管 / 主管 / 顾问，菜单与按钮按权限矩阵实时变化
  • · 列表筛选、列配置、批量选择、分页、排序
  • · 弹窗（新建/分配/标记伪线索/转商机）、抽屉（跟进记录）
  • · 手机号脱敏与「查看完整手机号」留痕提示
  • · SVG 折线图 / 环形图 / 转化漏斗 / 阶段看板拖拽
原型边界
  • · 纯静态 HTML + CSS + 原生 JS，无后端与真实数据
  • · 数据均为演示用示例，操作不产生真实业务变更
  • · 权限控制在前端演示层面实现，正式版本须由接口层二次校验
  • · 图表为手写 SVG，不依赖任何第三方图表库
  • · 未覆盖：支付、合同签署、外呼系统对接、教学交付
