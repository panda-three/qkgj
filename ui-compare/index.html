线索管理

原始原型

leads.html

静态演示数据，交互为假效果

  • 排序仅切换图标，无真实排序
  • 全选仅限当前页，翻页即丢
  • 完整手机号直接写在 DOM 属性里
  • 无移动端适配，表格需横向滚动
 改造版

leads.html

接入真实数据库数据，可操作

  • 真实排序 + 状态指示 + NULL 排后
  • 跨页选择保持，显示跨页数
  • 手机号脱敏，点击查看并留痕
  • 768px 断点：侧栏变抽屉、表格变卡片
  • 底部角色切换器，可对比三种权限视角
