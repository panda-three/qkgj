# 界面对比说明

## 怎么看

```
ui-compare/
├── index.html          ← 从这里进入（对比入口）
├── original/           ← 原始原型，逐字节复制自 prototype/，未改动
└── redesign/           ← 改造版
    ├── leads.html      线索管理（数据已内联，可直接双击打开）
    ├── data.json       从数据库导出的真实数据（HTTP 环境备用）
    └── assets/
        ├── compare.css 改造版样式
        └── compare.js  改造版交互逻辑
```

**打开方式**：直接双击 `ui-compare/index.html`，或用浏览器打开。

> 改造版的数据同时内联在 HTML 里和 `data.json` 中。
> 浏览器以 `file://` 协议打开时会拦截本地 JSON 的读取（CORS 限制），
> 内联是为了让双击打开也能正常工作。两者内容始终一致，
> 重复执行导出脚本不会导致内联块累积。

**刷新数据**：改数据库后执行

```bash
npm run preview:export
```

**验证改造版**：

```bash
npm run test:preview
```

## 两版的核心差异

### 一、响应式（最大的改动）

原型的 CSS 只有桌面端布局，`min-width` 设置后靠横向滚动应对窄屏。
在手机上体验是灾难：表格要左右拖，操作列被挤出屏幕，侧栏占掉 1/3 宽度。

改造版设了三个断点：

| 断点 | 变化 |
| --- | --- |
| < 768px | 侧栏变抽屉（汉堡按钮唤起）；表格换成卡片列表；弹窗变底部抽屉 |
| 768–1023px | 侧栏常驻，筛选区两列，分页横向排布 |
| ≥ 1024px | 筛选区三列 |
| ≥ 1280px | 筛选区四列 |

**为什么表格要换成卡片列表**：线索表有 12 列，横向滚动会让"操作"列永远看不到，
而跟进、转商机这些是最高频的操作。卡片列表按信息优先级重排：
姓名和状态在第一行，手机号和渠道在第二行，跟进次数和超期提醒在第三行。

### 二、交互反馈

| 项目 | 原型 | 改造版 |
| --- | --- | --- |
| 排序 | 点一下换图标，顺序没变 | 真实排序，NULL 统一排最后，当前排序列高亮 |
| 全选 | 仅当前页，翻页即丢 | 跨页保持，显示"跨 N 页"提示 |
| 手机号 | `data-phone` 属性里是完整号码 | 默认脱敏 `138****5678`，点击才显示完整号码，并提示"已记录操作日志" |
| 空状态 | 无 | 说明为什么空 + 给下一步动作按钮 |
| 批量操作 | 无反馈 | Toast 提示成功/失败条数，失败时说明原因 |
| 大批量 | 无提示 | 选中超 100 条时提示"建议分批操作" |
| 破坏性操作 | 直接执行 | 二次确认弹窗，说明后果（如"历史跟进记录会完整保留"） |

### 三、无障碍

- 所有可交互元素有 `:focus-visible` 焦点环，仅键盘可见
- 弹窗用 Radix 同款的焦点陷阱，ESC 可关，关闭后焦点归位
- Toast 用 `aria-live="polite"`，读屏器会播报但不打断当前朗读
- 页面顶部有"跳到主要内容"链接，键盘用户可直接跳过导航
- 表格排序按钮带 `aria-sort`，页码带 `aria-current`
- 弹窗有 `aria-modal` + `aria-labelledby`
- 尊重 `prefers-reduced-motion`：关掉所有动效
- 尊重 `prefers-contrast: more`：加粗边框
- 打印样式：自动隐藏侧栏、顶栏、批量条

### 四、权限视角对比

改造版右下角有**角色切换器**，可在三种视角间切换，直接看到数据权限的实际差异：

| 视角 | 可见线索数 |
| --- | --- |
| 超级管理员 | 12 条（全部） |
| 销售主管 | 本部门及下属 |
| 销售顾问 | 仅本人 + 公海 |

切到"顾问"视角后，"归属人""所属部门"两列会隐藏——这不是前端藏按钮，
而是服务端返回的数据里就没有别人家的线索。

## 生产环境的实现位置

改造版是**静态预览**，用于对比和评审。正式代码在 Next.js 项目里：

| 预览页元素 | 生产实现 |
| --- | --- |
| 线索列表 | `src/app/(app)/leads/page.tsx` + `LeadListClient.tsx` |
| 数据查询与权限 | `src/server/services/leadQuery.ts`（SQL 层拼接权限） |
| 手机号脱敏 | `src/components/business/PhoneCell.tsx` |
| 查看完整号码 | `src/app/api/phone/reveal/route.ts`（二次校验 + 日志留痕） |
| 基础组件 | `src/components/ui/`（Button / Field / Modal / Toast / ListControls / Layout / Feedback） |

生产的线索页支持完整的键盘操作与读屏器支持，
静态预览为了便于评审做了适度简化。
